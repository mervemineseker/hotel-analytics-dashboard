# 🏨 Hotel Analytics Dashboard (Power BI + SQL)

## 📋 Project Overview
This project visualizes key performance indicators (KPIs) from a hotel dataset using **Power BI**.  
It provides insights into revenue generation, occupancy rate, average daily rate (ADR), and RevPAR,  
helping hotel managers and analysts make data-driven decisions.

---

## 🎯 Objectives
- Analyze **total revenue**, **ADR**, **RevPAR**, and **occupancy trends**.
- Compare performance by **market segment**, **arrival period**, and **hotel type**.
- Build an **interactive Power BI dashboard** with dynamic filters and slicers.

---

## 🧩 Data Source
The dataset was obtained from **Kaggle** (Hotel Booking Demand Dataset).  
It contains information about reservations, guests, and hotel performance metrics.

---

## ⚙️ Tools & Technologies
- **Power BI Desktop** – dashboard creation & visualization  
- **Power Query** – data cleaning & transformation  
- **SQL (optional)** – for data preprocessing and KPI calculation  
- **Excel / CSV** – initial data source

---

## 📊 Dashboard Features
- **KPI Cards:** Total Revenue (€), ADR (€), RevPAR (€), Occupancy Rate (%)  
- **Slicers:** Market Segment, Arrival Period, Hotel Type  
- **Bar Chart:** Total Revenue by Hotel Type  
- **Interactive Filtering:** real-time updates across visuals  

---

## 📈 Insights
- Corporate and Online TA segments generate the highest revenue.  
- City hotels show higher ADR and occupancy compared to resort hotels.  
- Off-season periods (Nov–Feb) display noticeable drops in RevPAR.
